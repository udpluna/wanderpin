## Free services used (no API keys)
- **OpenFreeMap** vector maps (free, no limits): https://openfreemap.org. Style data © OpenMapTiles.
- **OpenStreetMap** data and classic tiles (© OpenStreetMap contributors, ODbL). Classic tiles follow the OSMF Tile Usage Policy: the app sends an identifying User-Agent and caches tiles for 7 days.
- **Esri World Imagery** satellite layer (non-commercial use): © Esri, Maxar, Earthstar Geographics.
- **Photon** geocoder by komoot: https://photon.komoot.io
- **Nominatim** (fallback search): https://nominatim.org, max 1 request per second, which the app enforces.
- **FOSSGIS OSRM** routing: https://routing.openstreetmap.de, max 1 request per second, which the app enforces.
